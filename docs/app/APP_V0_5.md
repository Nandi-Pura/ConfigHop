# App v0.5

The Firewall workspace uses manual source and target hardware selectors and manual PAN-OS train selectors. Verified profiles show their official evidence links and review date. Parsed source version is displayed separately from the selected train. Target options come from the selected profile: PA-5410 ports 1–24 are enabled; breakout 25–40 and conditional native QSFP 41–44 are visible but disabled.

The hardware check evaluates every effective target, including unchanged interface names. Preview and candidate requests include platform and hardware status. Blocking findings prevent generation; warnings require explicit engineer review. Candidate download still requires Core validation and preservation audit. The Switch workspace remains a frontend mock.
