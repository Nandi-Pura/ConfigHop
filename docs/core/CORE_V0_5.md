# Core v0.5 hardware compatibility

The curated [evidence registry](../../backend/src/confighop_core/evidence/registry.py) records six official Palo Alto sources checked on 2026-10-05. Evidence is a versioned snapshot; runtime operation needs no network access. The API exposes source titles, links, scope, and short summaries.

PA-3410 has 26 dataplane identities: 1–12 RJ45, 13–22 SFP/SFP+, and 23–26 SFP/SFP+/SFP28. PA-5410 has 24 directly candidate-ready identities (1–24), 16 breakout children (25–40), and four conditional native QSFP identities (41–44). Children 25–28 belong to 41, 29–32 to 42, 33–36 to 43, and 37–40 to 44. Neither breakout children nor native QSFP parents are candidate targets in v0.5. The [official front-panel reference](https://docs.paloaltonetworks.com/hardware/pa-5400-hardware-reference/pa-5400-series-firewall-overview/pa-5400-series-front-and-back-panel-descriptions/pa-5400-series-front-panel) says auto speed defaults QSFP ports to breakout. ConfigHop does not render the native speed or breakout configuration, so those identities fail closed.

The selected source hardware and PAN-OS train are manual. The parser's exact version, preferring `detail-version`, cross-checks the selection. The [official compatibility matrix](https://docs.paloaltonetworks.com/compatibility-matrix/reference/supported-os-releases-by-model/palo-alto-networks-next-gen-firewalls) lists 10.2, 11.0, 11.1, 11.2, 12.1, and 12.2 for both profiles, with 12.x starting at 12.1.2. A bare 12.1 train is not enough to verify that floor.

Every source physical interface has an effective target: explicit mapping if provided, otherwise its preserved name. Compatibility checks source identity, target identity and mode prerequisites, configured speed, common speed capability, and media family. A warning requires `allow_review`; errors always block before the renderer. Core v0.2 and v0.3 retain their existing dependency and preservation responsibilities. No automatic mapping, target speed rewrite, PAN-OS upgrade, or device connection is performed.
