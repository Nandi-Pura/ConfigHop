# Core v0.7 platform catalog

The evidence registry stores official source records. `hardware/palo_alto.py` declares exact Palo Alto model ports and per-profile PAN-OS rules; `hardware/registry.py` validates references and provides exact lookup and deterministic filtered listing. Registered profiles explicitly carry `domain=firewall` and `software_family=pan_os`. The Switch backend remains disabled.

The 11 verified models are PA-1410, PA-1420, PA-3220, PA-3250, PA-3260, PA-3410, PA-5220, PA-5250, PA-5260, PA-5280, and PA-5410. One synthetic development profile remains. The nine new models are usable as sources and analysis targets. Only PA-3410 and PA-5410 have verified candidate target rendering. An analysis-only target yields `TARGET_PROFILE_RENDERING_NOT_VERIFIED` and cannot generate a candidate, including with review acknowledgement.

PAN-OS support comes from explicit rules for the matrix trains 10.1, 10.2, 11.0, 11.1, 11.2, 12.1, and 12.2. An absent train is `VERSION_NOT_VERIFIED`; an explicit unsupported train is `UNSUPPORTED`. A supported 12.1 rule carries a 12.1.2 minimum. `first_supported_release` is metadata and does not imply support for historical trains. Legacy train lists are derived from these rules.
