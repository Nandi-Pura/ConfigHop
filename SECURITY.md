# Security Policy

## Reporting a Vulnerability

Email suspected ConfigHop security issues to **nandipura09@gmail.com** with a subject such as `[ConfigHop Security] Short description`.

Do not open a public GitHub issue for a confidential vulnerability or publish exploit details before coordinated disclosure. Send enough detail for investigation using synthetic or sanitized reproductions. Remove IP addresses, account identifiers, secrets, and customer topology. Do not include live credentials, customer firewall or switch configurations, or production packet captures containing sensitive information.

This project has no bug bounty program or guaranteed response time.

## Supported Security Scope

ConfigHop is a Beta / Technical Preview offline configuration migration workbench. Security reports may concern its implemented, bounded software behavior. Generated configurations require engineer review. Device import, packet-flow equivalence, and production suitability have not been certified.

## Coordinated Disclosure

Please allow the maintainers an opportunity to investigate a report before public disclosure. Provide sanitized steps to reproduce the issue and the expected impact. No fixed response or remediation deadline is promised.
